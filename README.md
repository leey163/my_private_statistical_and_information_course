# 概率论与信息论长期学习课程（第 1 层数学投资）

> 本仓库服务于 LLM 后训练的“分布思维”：目标不是成为通信理论研究者，而是成为**能从目标函数读出分布假设、行为偏向、估计边界与失效模式的人**。
>
> 它与 `my_private_llm_study_course` 的 24 周后训练课程锚定。建议先完成 `my_private_statistical_inference_course` 的 M1–M3，再以每周 2–3h 的节奏学习本课程，预计 5–6 个月。

## 1. 在四大数学支柱中的位置

| 支柱 | 本仓库职责 | 不由本仓库承担 |
|---|---|---|
| 概率分布与信息论 | **主责**：分布、熵、KL、最大熵、信息损失、散度选择 | 偏好是否合理、优化算法能否找到解 |
| 偏好与排序统计模型 | 只解释分布与 loss 的接口 | BT/Thurstone/PL、异质偏好、社会选择应由第 3 层承担 |
| 随机优化与 RL 理论 | 只解释最优分布与散度结果 | KKT、对偶、policy gradient、求解动态由 `my_private_optimize_course` 主讲 |
| 统计推断与实验设计 | 只提示估计问题 | 区间、检验、校准、一致性由 `my_private_statistical_inference_course` 主讲 |

> **跨仓库分工原则**：信息论回答“目标分布是什么、为何呈现这种分布行为”；优化理论回答“它怎样从约束问题产生、算法怎样近似找到它、何时找不到”。

## 2. 深度定标

| 档位 | 定义 | 课程选择 |
|---|---|---|
| L1 会用 | 知道交叉熵、KL 的公式，会调用库 | ❌ 太浅 |
| **L2 能解释与推演** | 能推导常用恒等式；知道散度、熵与互信息的假设和估计边界；能把后训练目标还原为分布优化问题，并区分分布解释与偏好/优化假设 | ✅ 目标档 |
| L3 能创造 | 做信息论或最优传输的新理论 | ❌ 不投入 |

> **L2 操作性判据**：拿到 SFT、DPO、IPO、KTO、PPO、GRPO 或蒸馏目标，能在纸上写出它涉及哪些随机变量和分布、使用什么散度/正则/链接函数、散度方向可能带来什么偏向、token-level 与 sequence-level 对象有何区别，以及日志中的量究竟是定义值还是采样代理。

## 4. 四种练习方法

1. **模拟验证法**：已知真分布造数据，数值估计熵/KL/MI；故意使用小样本、零概率、错配模型、长度混杂和错误采样分布让估计失败。
2. **推导重演法**：核心推导脱离资料重演，包括交叉熵分解、序列 KL 链式分解、最大熵分布和 KL 正则最优策略。DPO 主链每月重写一次。
3. **算法锚定法**：交叉熵回到 SFT loss；KL 回到 PPO/DPO；熵回到采样和探索；所有概念都要回到已经跑过的日志。
4. **目标函数审计法**：每两周选一个方法，区分散度、链接函数、风险函数、反馈形式、reference policy 与求解器；禁止把所有偏好优化目标笼统归结为“换散度”。

## 5. 明确不学

- 信道容量、编码定理、纠错码与通信系统工程
- 率失真理论深水区
- 测度论级严格化
- 最优传输的 PDE、Kantorovich 严格证明与 Wasserstein 梯度流
- 神经互信息估计器和信息瓶颈理论争议的深水区

## 6. 总资料索引

- **主线**：David MacKay, *Information Theory, Inference, and Learning Algorithms*（ML 视角）
- **查证**：Cover & Thomas, *Elements of Information Theory*（重点 ch2、ch8、ch11）
- **视频**：MacKay Cambridge lectures；Stanford EE274 前半；StatQuest 的 entropy/KL/cross-entropy 视频
- **实践**：`dit`、`scipy.stats.entropy`、Hugging Face TRL 中 reference log-prob 与 KL 实现
- **后训练材料**：DPO/IPO/KTO 原论文；John Schulman “Approximating KL Divergence”
